📥 安装插件

1
下载插件

在 Web 管理台的 「浏览器插件」 页面下载最新插件包

或者直接去 下载最新版

2
解压

将 zip 包解压到任意文件夹，记住这个位置。

3
加载扩展

浏览器地址栏输入 chrome://extensions（Edge 用 edge://extensions）

打开右上角 「开发者模式」 开关，点击 「加载已解压的扩展」，选择解压后的文件夹。

4
配置 API 连接

右键扩展工具栏图标 → 「选项」或「设置」，填入 API URL 和 Token。

⚙️ 配置 API 连接

1
获取 API URL

你的服务地址：https://marksync.zcoolq.cn/api

如果部署在本地：http://localhost:3000/api

2
创建 API Token

登录 Web 管理台 → 「API Token」页面 → 点击「创建新 Token」

创建后复制 mks_xxx 格式的 Token（可随时在列表中点 👁️ 查看）

3
测试连接

在扩展设置页面填入 URL 和 Token 后，点击「测试连接」验证。

🔄 同步指南

📤
本地同步到云端

将浏览器当前的书签上传到服务器。同一书签不会重复上传。

📥
云端同步到本地

将服务器上的书签下载到当前浏览器。

⚡
强制同步

用本地书签完全覆盖云端（不可恢复）。

⏰
自动同步

在扩展设置页面勾选「启用自动同步」，书签变更后自动上传到云端。

❓ 常见问题

插件无法连接？
  • 确认 API URL 以 /api 结尾
  • 确认 Token 未过期且在「API Token」页面未撤销
  • 如果使用 HTTPS，确保证书有效
  • Firefox 用户请打开 about:debugging#/runtime/this-firefox 加载
如何备份书签？

登录 Web 管理台 → 「备份与恢复」页面，可以设置自动备份或手动创建备份，随时可恢复。

数据安全性如何？

所有数据通过 HTTPS 加密传输，Token 在服务端使用 AES-256 加密存储。这是自托管方案，完全由你自己控制数据。

支持哪些浏览器？

支持 Chrome、Edge、Firefox（121+）。基于 Manifest V3。

Firefox 安装方式：打开 about:debugging#/runtime/this-firefox → 临时加载附加组件 → 选择解压后的 manifest.json

远程书签管理怎么用？

点击扩展弹窗的 🔍 按钮会打开 Web 管理台，登录后可在「书签管理」页面查看和编辑所有云端书签。
