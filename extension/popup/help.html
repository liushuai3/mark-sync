📦 安装插件

1
下载插件包

从 管理台「浏览器插件」 页面下载最新版 zip

或直接点击: 下载扩展 v3.1.5

2
解压到本地

将 zip 解压到任意文件夹, 请记住这个位置。

3
加载扩展

Chrome: chrome://extensions · Edge: edge://extensions · Firefox: about:debugging#/runtime/this-firefox

打开右上角 「开发者模式」, 点击 「加载已解压的扩展」, 选择解压文件夹。

4
获得 Token

登录 管理台 → 「API Token」→ 「创建新 Token」, 复制 mks_xxx 格式密钥。

⚙️ 配置扩展

1
打开设置

右键工具栏 MarkSync 图标 → 「选项」, 或点⚙️齿轮图标。

2
填写信息

API URL 默认已填 https://marksync.zcoolq.cn/api

自建后端可改为 http://your-server:port/api

Token 填入上一步复制的 mks_xxx 密钥

3
保存配置

点击「保存」, 自动执行首次合并, 状态栏显示合并结果。

之后每次保存会触发一次常规同步。

💡 API URL 默认指向 marksync.zcoolq.cn, 大多数用户无需修改, 直接填 Token 即可。

🔄 如何使用

▶
手动同步

打开扩展弹窗, 点击底部绿色 「立即同步」 按钮。

同步中按钮变黄色并旋转, 完成后 Toast 显示新增 / 修改 / 删除数量。

⏰
自动同步

后台每 5 分钟自动执行一次同步, 无需手动操作。

工具栏图标在同步中显示蓝色 ⋯, 同步完成短暂显示 ✓。

📊
查看状态

打开弹窗可查看:

  • 用户 — 当前登录用户
  • 服务状态 — ● 在线 / ✕ 离线 (自动检测后端健康)
  • 最后同步 — 最近一次同步时间 (超过 24h 显示完整日期时间)
  • 本地书签 — 浏览器中实际的书签数量
  • 远程书签 — 云端存储的书签数量
🌐
远程管理

点击弹窗顶部 📖 书本图标打开管理台, 在线查看/搜索/编辑云端书签。

⚠️ 首次同步会执行「合并」而非「覆盖」, 智能匹配去重, 不会丢失数据。

💻 多设备同步

1
第二台设备

在新浏览器上按「安装」→「配置」流程再来一次。

2
首次合并

新设备保存配置后自动执行 initialMerge, 本地与云端书签智能匹配。

匹配上的书签建立映射关系; 本地独有的推上去; 云端独有的拉下来。

3
日常同步

之后每 5 分钟自动增量同步, 可以手动点「立即同步」触发。

💡 多个浏览器使用同一个 同一个 Token 即可共享书签数据。不同用户请创建对应 Token。

❓ 常见问题

插件无法连接或显示「✕ 离线」
  • 确认 API URL 以 /api 结尾, 如 https://marksync.zcoolq.cn/api
  • 确认 Token 未过期且在管理台「API Token」页面状态正常
  • 如果使用自定义 HTTPS, 确保证书有效
  • 查看管理台同步日志确认服务器端是否有错误
本地书签和远程书签数不一致

本地书签 是当前浏览器中实际的书签数量（含 chrome 根文件夹）。

远程书签 是同步到服务器上的活跃书签数量（不含已删除的记录）。

不一致正常, 点一次「立即同步」即会双向对齐。

支持哪些浏览器？

Chrome · Edge · Firefox 121+（基于 Manifest V3）。

Firefox 安装后需在 about:debugging#/runtime/this-firefox → 临时加载附加组件。

如何备份书签？

登录 管理台 → 「备份与恢复」页面, 可设置自动备份或手动创建备份随时恢复。

同步冲突怎么处理？

采用 LWW（Last-Writer-Wins）策略, 以较晚修改的版本为准。冲突不会导致数据丢失, 冲突数会显示在弹窗状态面板中。

数据安全性如何？

Token 在服务端使用 AES-256-GCM 加密存储（可随时在管理台查看/撤销）。

所有 API 通信通过 HTTPS 加密。全部数据由你自己掌控。

如何更新插件？

重新下载最新版 zip → 解压覆盖旧文件夹 → chrome://extensions 点 🔄 重新加载。

配置和数据不会丢失, 存储在 Chrome 同步存储中。

同步日志保留多久？

云端自动保留最近 10 天的同步日志, 超过自动清理。可在管理台「统计」页面查看。

能离线使用吗？

扩展弹窗打开时会自动检测后端健康状态。当后端不可用时, 扩展不会操作本地书签, 待恢复连接后下一次同步自动对齐。
